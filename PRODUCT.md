# Mirror Image

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People trying the app in a demo, plus recruiters and technical reviewers. The user confirmed that the demo experience takes priority and technical details should remain accessible.

## Product Purpose

Match a live camera expression to meme profiles, making the computer-vision interaction easy to demonstrate and explore.

## Operating Context

A browser application used on desktop and phones. The main workflow is starting the camera and comparing the live expression with the closest meme. Library and Settings support profile management and inspection.

## Capabilities and Constraints

Existing implementation provides face and hand tracking, expression matching, calibration, built-in and custom meme profiles, profile editing, import/export, and tracking diagnostics. Camera processing runs in the browser. Custom profiles and edits are stored locally. Preserve these capabilities and the existing React, TypeScript, and Vite implementation.

## Brand Commitments

Retain the Mirror Image name. Use straightforward, professional wording. Avoid playful slogans and unnecessary promotional copy. The user requested a clean presentation suitable for showing to other people and a layout that works well on phones.

## Evidence on Hand

The working application, existing meme assets, and source implementation provide the product evidence. No customer claims, testimonials, or performance benchmarks have been supplied.

## Product Principles

- Make the camera-to-match interaction clear to a first-time visitor.
- Keep technical detail available without overwhelming the main demo.
- Preserve real tracking and profile behavior.
- Support touch and narrow screens alongside desktop use.
