# Almarts27 hamster references

These four local images are drawings by Instagram artist **Art by Alma
(@almarts27)**. Each retained drawing has a trained profile in
`src/data/memes.json` and participates in live matching.

- Collection overview: https://knowyourmeme.com/memes/hamster-drawing-memes-almarts27-hamster
- Original artist: https://www.instagram.com/almarts27/
- Gallery copies: `alma-hamster-<photo-id>.<extension>` map to
  `https://knowyourmeme.com/photos/<photo-id>-hamster-drawing-memes-almarts27-hamster`
- Retrieved: 2026-09-19

The retained photo IDs are 3132149, 3132151, 3132152, and 3273252. Images the
user removed from the browser library are no longer bundled with the project.
