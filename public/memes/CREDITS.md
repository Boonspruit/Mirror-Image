# Meme image sources

These are locally stored copies of public meme templates for the Mirror Image prototype.
The source pages identify the exact downloaded variants; they are not license grants.
Images remain subject to their original owners’ rights. No ownership or public-domain status is claimed.

All expression profiles are manually estimated human imitations, not MediaPipe measurements.
Head pose is intentionally null for every entry.

## Almarts27 hamster reference set

- Files: `/memes/alma-hamsters/alma-hamster-*`
- Artist: Art by Alma ([@almarts27](https://www.instagram.com/almarts27/))
- [Collection and image sources](https://knowyourmeme.com/memes/hamster-drawing-memes-almarts27-hamster)
- Retrieved: 2026-09-19
- Status: all sixteen locally stored drawings have manual expression profiles and are included in live matching

These drawings remain subject to the artist's rights. See the README inside the
asset folder for the per-file source URL pattern.
